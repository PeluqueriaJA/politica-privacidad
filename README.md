# Política de privacidad · Peluquería Juan Alfonso

Documento de política de privacidad de Peluquería Juan Alfonso (Barcelona), 
sobre el tratamiento de datos personales en la gestión de citas por teléfono, 
incluido el asistente de inteligencia artificial que atiende las llamadas.

🔗 Ver la política de privacidad: https://peluqueriaja.github.io/politica-privacidad/

Conforme al Reglamento (UE) 2016/679 (RGPD) y a la Ley Orgánica 3/2018 
de Protección de Datos Personales y garantía de los derechos digitales.
